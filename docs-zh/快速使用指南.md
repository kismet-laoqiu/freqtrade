## 🔧 常见任务

### 创建新策略
```bash
# 创建策略文件
freqtrade new-strategy --strategy MyStrategy

# 编辑策略
# 参考：策略入门 101
```

### 下载数据
```bash
# 下载历史数据
freqtrade download-data --exchange binance --pairs BTC/USDT ETH/USDT --timeframes 5m 1h
```

### 运行回测
```bash
# 回测策略
freqtrade backtesting --strategy MyStrategy --timeframe 5m
```

### 启动交易
```bash
# 模拟交易
freqtrade trade --strategy MyStrategy --dry-run

# 实盘交易（谨慎！）
freqtrade trade --strategy MyStrategy
```

## ⚠️ 重要提醒

### 风险警告
1. **永远不要投入您承受不起损失的资金**
2. **始终先进行充分的回测**
3. **在模拟模式下运行足够长时间**
4. **了解您使用的策略的风险**

### 最佳实践
1. **从小额开始**：先用少量资金测试
2. **分散风险**：不要把所有资金投入一个策略
3. **持续监控**：定期检查机器人状态
4. **保持学习**：持续改进您的策略

1. **文档优先**：先查看相关文档
