# 杠杆交易

!!! Warning "Beta 功能"
    此功能仍处于测试阶段。如果您发现任何您认为有问题的地方，请通过 Discord 或 Github Issue 告知我们。

!!! Note "一个账户上的多个机器人"
    您不能在同一个账户上运行 2 个带杠杆的机器人。对于杠杆/保证金交易，freqtrade 假设它是账户的唯一用户，所有清算水平都基于此假设计算。

!!! Danger "杠杆交易风险极高"
    不要使用杠杆 > 1 交易尚未在现货市场实盘运行中显示正面结果的策略。检查您策略的止损。使用 2 倍杠杆时，0.5（50%）的止损会太低，这些交易会在达到止损之前被清算。
    我们不对使用此软件或此模式可能发生的损失承担任何责任。

    请仅在您了解 freqtrade（和您的策略）如何工作时使用高级交易模式。
    此外，永远不要冒险超过您能承受的损失。

如果您已经有现有策略，请阅读[策略迁移指南](strategy_migration.md#strategy-migration-between-v2-and-v3)将您的策略从 freqtrade v2 策略迁移到可以做空和交易期货的版本 3 策略。

## 做空

当 [`trading_mode`](#杠杆交易模式) 设置为 `spot` 时，无法做空。要进行空头交易，`trading_mode` 必须设置为 `margin`（目前不可用）或 [`futures`](#期货)，并且 [`margin_mode`](#保证金模式) 设置为 `cross`（目前不可用）或 [`isolated`](#隔离保证金模式)

要使策略做空，策略类必须设置类变量 `can_short = True`

请阅读[策略自定义](strategy-customization.md#entry-signal-rules)以获取如何设置信号进入和退出空头交易的说明。

## 理解 `trading_mode`

可能的值是：`spot`（默认）、`margin`（*目前不可用*）或 `futures`。

### 现货

常规交易模式（低风险）

- 仅多头交易（无空头交易）。
- 无杠杆。
- 无清算。
- 获得/损失的利润等于资产价值的变化（减去交易费用）。

### 杠杆交易模式

使用杠杆，交易者从交易所借入资本。资本必须完全偿还给交易所（可能带有利息），交易者保留任何利润，或支付任何损失，来自使用借入资本进行的任何交易。

因为资本必须始终偿还，当杠杆账户中资产的总价值下降到某个点时（总损失价值小于交易者在杠杆账户中实际拥有的抵押品价值的点），交易所将**清算**（强制出售交易者资产）使用借入资本进行的交易，以确保交易者有足够的资本将借入的资产偿还给交易所。交易所还将收取**清算费用**，增加交易者的损失。

因此，**如果您不确切知道自己在做什么，请不要进行杠杆交易。杠杆交易是高风险的，可能导致您的资产价值很快下降到 0，没有再次增值的机会。**

#### 保证金（目前不可用）

交易发生在现货市场上，但交易所向您借出等于所选杠杆的货币金额。您向交易所偿还借给您的金额加上利息，您的利润/损失乘以指定的杠杆。

#### 期货

永续掉期（也称为永续期货）是以与其基于的基础资产（例如）密切相关的价格交易的合约。您不是在交易实际资产，而是在交易衍生品合约。永续掉期合约可以无限期持续，与期货或期权合约形成对比。

除了期货合约价格变化的收益/损失外，交易者还交换_资金费用_，这是价值等于期货合约和基础资产之间价格差异的收益/损失。期货合约和基础资产之间的价格差异在不同交易所之间有所不同。

要在期货市场交易，您必须将 `trading_mode` 设置为 "futures"。
您还必须选择一个"保证金模式"（下面解释） - freqtrade 目前仅支持隔离保证金。

``` json
"trading_mode": "futures",
"margin_mode": "isolated"
```

##### 交易对命名

Freqtrade 遵循 [ccxt 期货命名约定](https://docs.ccxt.com/#/README?id=perpetual-swap-perpetual-future)。
因此，期货交易对将具有 `base/quote:settle` 的命名（例如 `ETH/USDT:USDT`）。

### 保证金模式

除了 `trading_mode` 之外 - 您还必须配置您的 `margin_mode`。
虽然 freqtrade 目前仅支持一种保证金模式，但这将改变，通过现在配置它，您为未来的更新做好了准备。

可能的值是：`isolated` 或 `cross`（*目前不可用*）。

#### 隔离保证金模式

每个市场（交易对）在单独的账户中保留抵押品

``` json
"margin_mode": "isolated"
```

#### 全仓保证金模式

一个账户用于在市场（交易对）之间共享抵押品。需要时从总账户余额中提取保证金以避免清算。

``` json
"margin_mode": "cross"
```

请阅读支持此模式的交易所的[交易所特定说明](exchanges.md)以及它们的差异。

## 设置要使用的杠杆

不同的策略和风险配置文件将需要不同级别的杠杆。
虽然您可以配置一个静态杠杆值 - freqtrade 为您提供通过[策略杠杆回调](strategy-callbacks.md#leverage-callback)调整此值的灵活性 - 这允许您按交易对使用不同的杠杆，或基于有利于您策略结果的其他因素。

如果未实现，杠杆默认为 1x（无杠杆）。
