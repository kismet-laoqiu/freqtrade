## 翻译质量和特点

### 翻译原则
1. **准确性**：保持技术术语的准确性
2. **一致性**：统一的术语翻译
3. **可读性**：符合中文表达习惯
4. **完整性**：保留所有原文信息

### 术语对照表
- Strategy → 策略
- Trade → 交易
- Backtesting → 回测
- Pair → 交易对
- Timeframe → 时间框架
- Indicators → 指标
- Entry/Exit → 入场/出场
- Dry-run → 模拟运行
- Live trading → 实盘交易

## 使用方法

### 1. 查看文档
直接打开 markdown 文件查看：
```bash
cd docs-zh
# 查看主页
cat index.md
# 查看特定文档
cat strategy-101.md
```

### 2. 使用 MkDocs 预览
如果安装了 MkDocs：
```bash
cd docs-zh
mkdocs serve
# 然后在浏览器中访问 http://localhost:8000
```

### 3. 继续翻译
对于占位符文档，您可以：
1. 查看英文原版：`docs/原文件名.md`
2. 编辑中文版本：`docs-zh/文件名.md`
3. 更新翻译状态标记
